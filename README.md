# USE — YouNing's Urban Transport Expansion

城市交通扩展模组，基于 [Architectury](https://github.com/architectury) 同时支持 Fabric 与 Forge。

## 支持版本

| Minecraft | Fabric | Forge |
|---|---|---|
| 1.20.1 | ✅ | ✅ |
| 1.19.4 | ✅ | ✅ |
| 1.19.2 | ✅ | ✅ |
| 1.18.2 | ✅ | ✅ |

依赖：[MTR (Minecraft Transit Railway)](https://modrinth.com/mod/minecraft-transit-railway)、Architectury API、Cloth Config。
